Four checks before enabling tools

  1. Verify local services

    Inspect Forgejo API and MCP protocol, not just the listening ports.

  2. Secure the source

    Upgrade unsupported Forgejo 11, rotate exposed credentials, create read-only token.

  3. Connect privately

    Use an approved private tunnel or authenticated HTTPS MCP service.

  4. Prove it in ChatGPT

    Discover tools and read a real repository, then cross-check the Forgejo UI.
